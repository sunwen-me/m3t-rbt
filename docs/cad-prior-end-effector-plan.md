# SO101：CAD 安装先验与夹爪优先的实施方案

日期：2026-11-14（Asia/Shanghai）
状态：当前范围已于 2026-11-15 收敛为固定 −61° 相机下的机械臂粗初始化；下文原多姿态安装修正方案保留为后续参考，当前不执行。

## 当前执行范围（2026-11-15 用户明确收敛）

用户目标是得到 Gemini335 在既有 −61° 双目标定锚点下，相对左右机械臂的大致六自由度关系，用作 M3T 初值。接受 CAD 名义装配作为粗安装先验，不要求本轮继续多角度云台测试、重做 −61° 双目标定或完成精密安装标定。

本轮仅需：

1. 保留既有 −61° Gemini335/Gemini2 标定与当前相机/云台名义安装链。
2. 组合每臂名义 `base_link` 到 `orbbec335/color_optical` 的位姿；左右臂采用用户更正后的标签。肩轴到 `base_link` 的偏移必须按底座朝向旋转后组合，不能直接复制肩轴点，也不能由一个点的测量凭空推断朝向。允许沿用明确标注来源的既有朝向作为粗假设。
3. 将安装位姿作为初始化 seed，并用当帧 v2 编码器反馈产生关节 seed。仅检查一张静止姿态叠加图里的左右、朝向和大致位置；偏差明显时只作有记录的初值调整。
4. 在输出中标明“名义 CAD/粗初始化”，与精密外参及在线安装优化区分。本轮不自动覆盖永久 TF、不启动电机运动。

**朝向已确认（2026-11-15）**：用户说明两臂底座正面都朝机器人前方。官方模型 `base_link` 的 +X 为底座正面；结合旧新基坐标转换记录，两臂统一采用 +X 前/+Y 左/+Z 上的名义旋转。底面水平、无额外滚转/俯仰作为粗初始化假设，不再要求用户补测朝向；右臂不能直接照搬旧模型未迁移的 +90°。

**当前输出**：[固定 −61° 名义安装先验](../calibration/fixed_pitch61_nominal_mounts.json) 只提供两臂 `base_link` 在 `orbbec335/color_optical` 中的粗位姿，不是含关节状态的可运行初始化文件。肩轴布局沿用用户确认的左近右远、两侧均位于云台下方；将横向符号和下方高度规范化用于粗 seed，前向约 60 mm 作为显式粗假设，原始 Fusion 读数仍完整保留。关节角须在实际启动时读取新鲜 v2 编码器反馈，不填零值或冒充历史值为当前值。永久 TF 未改；本先验已于 2026-11-15 接入双臂实验入口：一个 M3T 进程/Tracker、左右各一个 Optimizer，单个相机帧统一输出两臂位姿；12 项实时关节软先验已生效。旧单左臂跟踪已停止，入口保留可回退。实际 initialization 使用本次只读 v2 反馈的六项关节 seed；M3T Region + Depth 已输出，六项软先验均生效。实验保留 `fixed_base=true`，不会在线修正底座安装。云台角度明确使用固定 −61° 假设，不伪装为实时反馈。

下面的 A/B/C/D、多姿态共享优化、留出验证和精密验收门槛属于后续提高精度的参考方案，不是本轮 M3T 粗初始化的前置条件。

## 1. 目标与已知边界

目标是得到可验证的夹爪刚性参考系在主相机中的位姿，并使整条机械臂的解释符合装配与编码器反馈。验收首先看末端；全臂视觉误差不应凭像素数量压过夹爪误差。

已知事实：

- 当前网页实验将物理 base 硬固定在一个未通过手眼 solver 验收的实验初值；五轴角度先验 sigma=0.1 rad，夹爪 sigma=0.01 rad。曾观测到肘部约 -25°、腕弯约 +36° 的修正和肩抬到限位，不能据此认定视觉更准确。
- 用户确认实物 Gemini335、支架、孔位和朝向与提供的整机 STEP 一致；这属于名义装配来源确认，不等于公差、零位或回差测量。
- 云台原点已使用用户截图选取的 DM3510 中央顶面圆心；官方 RGB 原点尺寸已组合进当前 TF，-61° 双目锚点保留。此步骤没有重新求准左臂安装初值。
- 用户已明确纠正：之前左右标签反了，完整读数应交换。正确的左肩轴距离为 530.434 mm，增量 [60.292,-82.331,+520.525] mm；右肩轴距离为 545.123 mm，增量 [60.681,+150,-520.525] mm。右分量合成 545.095 mm（与所报距离差约 0.028 mm）。两臂位于云台下方左右两侧，左臂更近。原始标签与纠正来源保留在测量记录中；交换标签不等于验证了 Fusion 轴向、点选方向或底座朝向，尚不可把这些向量直接写成完整运行 TF。
- `shoulder_link` 原点 S 在 `base_link` 中为 [38.8353,-0.00000897657,62.4] mm。若量的是舵机中央小凸起顶面，该点比 S 高 1.5 mm，必须显式转换。
- 目前实时 pitch 反馈曾离线并报 No buffer space available。移动云台与相机/反馈时序暂不纳入首版实验。

本轮不承诺毫米级实物精度，也不把 CAD 与旧 TF 的两厘米差直接当成机械公差或先验 sigma。

## 2. 主决策：安装校准与实时跟踪分开

同一个夹爪观测不能可靠地区分任意 base 六自由度修正和所有关节角修正。首版采用两个明确模式：

1. **安装校准模式**：保持机械臂各关节使用实际稳定反馈，不同时拟合关节零位；让 CAD base 的小量六自由度修正成为待估量。多姿态共享一份安装修正。
2. **跟踪模式**：使用通过验证的安装修正，在一次运行中固定该安装参数；各关节继续融合编码器软先验与视觉。不能每帧重新自由拟合一份安装 TF。

这不会再次硬锁到原来未验证的初值：先通过 CAD 先验与多姿态观测估计并验证安装修正，随后才冻结。若以后需要在线慢变安装修正，应作为独立后续功能，先证明多帧约束与可观测性，再开放；不在首版同时加入。

如果固定关节反馈时，多姿态仍不存在一致的安装修正，则停止安装拟合的接受流程，检查关节零位/方向、模型、贴码安装和图像深度。不得扩大 base 自由度来掩盖这些误差。

## 3. 坐标与输入

选择固定机身参考 W=`camera_pitch_base`（当前原点位于用户所选轴心），每臂 B=`base_link`，末端 G=`gripper_link`。以 C 表示主相机彩色光学系。

名义位姿与修正定义为：

```
T_W_B = T_W_B_CAD * Exp(delta_base)
T_C_G(i) = T_C_W(i) * T_W_B * FK(q_measured(i) + delta_q(i))
```

- `delta_base` 为该次安装共享的小量位置/旋转修正；右乘表示修正分量在名义 B 局部坐标中表达，必须固定这一约定。
- 安装校准阶段 `delta_q(i)=0`；实时跟踪阶段安装修正固定，`delta_q(i)` 由编码器软先验约束。
- Fusion 点距离不直接作为 T_W_B 的平移；必须先明确所量点、选择顺序和 Fusion→W 变换，再用 `T_W_B = T_W_S * inverse(T_B_S)` 换算。
- 一个肩轴中心点只能提供位置约束。底座朝向需要从 CAD 底面法向与前后基准（或至少三个非共线刚性点）获得。未确认的旋转不能伪装成高置信完整位姿。
- 输入清单记录来源、单位、方向、URDF/mesh 哈希、v2 标定身份、相机序列号/内参、各时间戳与实际 pitch。左右臂完全分开建立先验，先左臂验收，再扩到右臂。

## 4. CAD 安装软先验

安装优化中使用固定 CAD anchor、可修正物理 base，以及 anchor↔base 的六自由度软约束。内部 anchor 无视觉 Body，不改变公开机器人 URDF。物理 base 的既有输出仍表示修正后的位姿；内部 anchor 单独记录到诊断，不伪装成实物 link。

采用 upstream `Link` / `SoftConstraint` 表达，不增加另一套框架优化器。SoftConstraint 的平移/旋转 sigma 分别设置，单位 m/rad。首版优先使用零死区高斯约束；若使用非零 dead zone，必须明确区间内无恢复力。

重要区别：sigma/死区是软代价，不是硬限幅。另设独立接受门槛：修正超出经确认的安装范围、撞限位或可观测性不足时，该候选不接受。安装范围和 sigma 用名义基准可信度、重复观测及装配公差确定，不通过随意放宽参数让数据“过关”。

固定 CAD anchor 不随每一帧的视觉输出移动。重初始化明确支持清零安装实验修正；对已接受安装修正则从有来源的安装文件加载，避免重复相乘或无意覆盖。

参考 upstream：

- https://github.com/DLR-RM/3DObjectTracking/blob/master/M3T/include/m3t/link.h
- https://github.com/DLR-RM/3DObjectTracking/blob/master/M3T/include/m3t/soft_constraint.h
- Stoiber, *Closing the Loop*, §6.2.4，机器人本体测量、虚拟 link 与软约束。该思想不是即插即用的 SO101 成品标定器。

## 5. 夹爪优先的视觉配置

首版增加 per-link 模态选择和 YAML 覆盖：

| 几何组 | 首版角色 |
|---|---|
| `gripper_link` 刚性壳体、确定刚性连接的相机安装结构 | 主要 Region/Depth 观测 |
| `wrist_link`、清晰可见的末端刚性连接件 | 次要观测，帮助判断方向 |
| 上臂、前臂、肩部、base | 初版保留几何/遮挡/显示，视觉残差可关闭；作为对照再逐步加入 |
| 活动夹指 | 由独立开度反馈和既有关节结构约束，单独做观测验证 |
| 可变形软鳍 | 保留模型显示；首版不作为刚性精度判据，避免变形驱动 base/腕部错误修正 |

不能靠删 mesh 关闭视觉，否则会丢失遮挡几何。每个 link 保留 Body，独立控制挂接哪些 modality。

Region 与 Depth 的权重通过它们实际支持的噪声参数、采样数及模态配置管理；不虚构 upstream 已有任意 per-link loss 权重接口。必须记录有效采样数，验证采样数量变化没有让整个长臂压过小夹爪。真实遮挡应区分可见外轮廓和透视渲染线，后者只用于调试，不能当贴合指标。

末端目标是刚性参考系的 6D 位姿（位置+朝向），不能只要求2D轮廓重合。形状对称或深度不足时，标记相应方向观测不足，不声称全姿态已确定。

## 6. 采集与对照实验

先固定主相机/云台在 -61° 附近，只用 Gemini335 和左臂，关闭安装以外的新增变量。暂不加入双相机和动态 pitch，以隔离误差来源。

### 数据

建议准备12个不同静止姿态；采集前就指定8个拟合、4个验证，覆盖不同腕部位置和旋转。所有模式使用完全相同的图像、深度和反馈回放。不要根据拟合残差事后挑掉验证失败样本。

保存原始 RGB-D、相机内参/畸变/尺度、时间身份、前后反馈、实际 pitch、原始/修正位姿和全部来源哈希。软件时间配对继续标注为非曝光同步。人手摆姿态后停稳采集；本方案不授权自动运动。

夹爪 ID 1 标记必须固定在不随夹指开合移动的刚性位置，尺寸和贴码方向需确认。若 `T_G_marker` 可由 CAD/独立量测确定，优先使用该值；若必须联合估计它，只能用拟合集，验证集不得重新拟合。沿用旧 rejected-fit 的贴码位姿不能作为独立真值。单目标记姿态受像素/尺寸误差影响，应结合深度一致性报告，不把它当无噪声空间真值。

### 对照组

- A：当前实验初值 + 固定 base + 原视觉模式，作为基线。
- B：Fusion 名义安装 + 固定 base + 相同反馈，显示 CAD 本身能改善多少。
- C：CAD 软先验 + 多姿态共享安装修正，关节保持反馈值，末端视觉优先。
- D：冻结 C 的通过验证安装结果 + 末端优先 M3T + 逐关节软先验，评估连续跟踪。

只有 C 在预先留出的姿态上通过，才进入 D。固定关节下的修正若不稳定，先查误差来源，不再同时放开关节零位进行过度拟合。

## 7. 验收与失败条件

验收表至少分开记录：

1. 末端码框/刚性特征的独立重投影误差，及末端可见表面的深度残差；提供每姿态、中位数、P95、最坏值。
2. 在验证基准误差允许时报告末端位置/朝向误差（mm/deg），禁止由“轮廓看着贴”推断毫米精度。
3. 同一份安装修正在不同姿态、不同拟合子集下的一致性；平移/旋转修正大小以及是否触及设置的接受边界。
4. 每关节视觉修正相对实际反馈的角差、归一化误差（按 sigma）、限位情况；不能只报告 applied 6/6。
5. 帧/反馈年龄、遮挡有效观测数、丢失后的恢复、连续运行中的抖动与不确定状态。

安装/码观测继续执行已有 handeye 工程门槛：训练整体 RMS<=2 px、单训练姿态<=3 px、验证最大预测误差<=4 px；这些门槛只评价像素一致性，不能替代空间精度。独立物理精度目标应在基准噪声可测后冻结，不在实施前许诺5 mm或1°。

D 的接受条件：验证集的末端误差相对 A、B 明确改善，P95/最坏姿态不恶化；稳定姿态不持续撞限位，不再重复出现此前25°/36°的大修正；安装修正对多个姿态一致。任一违反必须输出原因和不可信状态，不能把显示贴合当已校准。若无法满足，保留A/B/C/D数据定位问题，不覆盖现网初值。

## 8. 代码范围和顺序

1. `calibration/`：增加经过坐标审计的 CAD 安装先验文件和只读姿态采集/回放清单；保留现有原始记录。
2. `include/rbt_m3t/model.hpp`, `src/model.cpp`：内部 CAD anchor、安装校准模式的 base 修正、跟踪模式冻结；per-link modality 配置；诊断中分开 anchor/修正后base/末端。
3. `include/rbt_m3t/app_config.hpp`, `src/app_config.cpp`：严格校验新增模式、单位、先验范围和 link 名。旧配置行为保持；模式冲突提前报错。
4. `calibration/m3t_preview.py`, `overlay_preview.py`：明确 A/B/C/D 和修正来源，显示安装修正与关节偏移，保存同帧结果；显示开关不影响优化。
5. 定向 C++/Python 测试、原生软件 fixture、ARM64 隔离验证；全部通过后再做只读实采对照。新结果独立目录并有回滚。

特别测试：非零关节 seed+非零base修正只能各组合一次；先验不得跟随视觉漂移；reinit/reset契约；关节噪声不能重复加入；没有主要末端观测时不接受安装修正；Body无modality时仍保留遮挡几何。

当前 `camera_motion` 强制物理 `fixed_base=true`，不可直接把它改为false后宣称支持CAD软先验。首版固定云台，动态扩展后续再处理“世界anchor固定、物理base可修正”的不同语义。Gemini335与胸部Gemini2也不属于同一随动刚体；双相机与动态pitch必须在正确动态外参、时序验证后再组合。

## 9. 交付与停止边界

首版交付应包含：左右CAD先验来源（先完成左臂）、A/B/C/D同数据报告、末端/关节/安装分项指标、独立验证结果、可复现命令、配置/二进制哈希、回滚文件。

本方案先修改和验证实验路径，不自动改 canonical URDF、v2电机标定、传感器factory外参或永久TF。安装修正只有通过验证、形成可审记录后才考虑正式发布。若仅完成软件测试，只报告实现/软件验证，不报告实机准确。
